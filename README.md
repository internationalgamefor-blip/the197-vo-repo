# the197-vo-repo

Voiceover (VO) generation scripts for The 197 history videos.

- generate_all.py — generates the main Russia video VO lines with ElevenLabs (voice: George), mood-matched per chapter.
- generate_shorts_vo.py — generates Shorts VO segments, same voice.
- elevenlabs.py — ElevenLabs API helper (user, voices, tts).

Requires an ElevenLabs API key — no key is included in this repo.
